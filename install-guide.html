Installing Eclipse IDE & the ENACT SDK

A step-by-step guide to get your development environment ready, install the Eclipse IDE, then add the ENACT Software Development Kit from either the Eclipse Marketplace or the p2 update site.

⏱ ~15 minutes ☕ Java 21+ 🧩 Eclipse 2025-12 (4.38)+ 💻 Windows · Linux · macOS

What you'll do

  1. Check prerequisites
  2. Install the Eclipse IDE
  3. Install the ENACT SDK
  4. Option A, Eclipse Marketplace
  5. Option B, p2 update site
  6. Verify the installation
Before you start

0Prerequisites

The ENACT SDK is an Eclipse plug-in suite. You need a recent Eclipse IDE and a Java 21 (or newer) runtime. Everything else is installed through this guide.

Already have Eclipse installed?

If your Eclipse is 2025-12 (4.38) or newer on Java 21+, skip straight to Step 2, Install the ENACT SDK.

Part one

1Install the Eclipse IDE

The quickest route is the official Eclipse Installer, which downloads and sets up a ready-to-use IDE package.

  1. Download the Eclipse Installer

    Go to eclipse.org/downloads and open the Download menu, then choose the build for your machine, Download x86_64 for most PCs, or Download AArch64 for Apple Silicon / ARM. This downloads the Eclipse Installer.

  2. Pick the “Eclipse IDE for Java Developers” package

    Launch the downloaded installer. From the list of packages, select “Eclipse IDE for Java Developers”, it includes everything the ENACT SDK needs.

  3. Choose the Java VM and install folder

    Confirm the Java VM the installer offers (a suitable Java 21+ JRE, the current installer ships Java 25), pick an Installation Folder, and click INSTALL. Accept the license agreement when prompted.

  4. Launch Eclipse and choose a workspace

    Click Launch when the install finishes. Eclipse asks for a workspace folder, this is where your projects live. Accept the default or pick your own, then click Launch.

Verify your Eclipse version

Open Help → About Eclipse IDE. Confirm the version is 2025-12 (4.38) or newer. If it's older, update Eclipse before installing the SDK.

Part two

2Install the ENACT SDK

There are two ways to install the SDK. Both install the complete SDK (all modules); you can deselect optional modules in the install wizard before finishing. Pick whichever you prefer.

Recommended

Option A, Eclipse Marketplace

Search & click Install from inside Eclipse. Easiest for most people. → Go to Option A

Option B, p2 update site

Add the update-site URL manually via “Install New Software”. → Go to Option B

Option A, Eclipse Marketplace

  1. Open the Eclipse Marketplace

    In the menu bar, choose Help → Eclipse Marketplace…

  2. Search for the ENACT SDK and click Install

    Type ENACT in the Find box and press Enter. Locate “ENACT Software Development Kit” (by Siemens, Apache 2.0) in the results and click Install.

  3. Confirm the features, accept the license, and restart

    Review the selected features (the complete SDK is pre-selected) and click Confirm. On the Review Licenses page, accept the Apache 2.0 license and click Finish. When the unsigned content warning appears, choose Install anyway / Trust Selected, then restart Eclipse when prompted.

    “Warning: unsigned content” is expected

    This Beta release ships unsigned JARs. It's safe to proceed for the hackathon, choose Install anyway / Trust Selected.

Shortcut: drag-to-install

You can also drag the Install button from the ENACT SDK landing page straight onto a running Eclipse workbench.

Option B, p2 update site

Use this if you'd rather add the update site by URL. This is the update-site address:

https://pages.eclipse.dev/eclipse-research-labs/enact-project/software-development-kit/releases/latest/

  1. Open “Install New Software”

    Choose Help → Install New Software…

  2. Add the update site and select the complete SDK

    Click Add… next to Work with, then in the Add Repository dialog set Name to ENACT SDK and paste the URL above into Location, and click Add. Back in the list, expand ENACT SDK, Complete and tick “ENACT SDK, Complete (install everything)”, then click Next.

  3. Review the install details

    On the Install Details page you'll see the complete SDK and each module it pulls in (Core, Application Packaging, AI Assistant, Dataspaces, Application Controller, Application Policies). Click Next.

  4. Accept the license, trust & restart

    Accept the Apache 2.0 license and click Finish. If the unsigned content warning appears, choose Install anyway / Trust Selected. Restart Eclipse when prompted.

    Want a specific version?

    A pinned release is always available at …/releases/<tag>/, for example …/releases/v1.3.0/, in addition to the latest alias used above.

Part three

3Verify the installation

After restarting, open the SDK control panel to confirm everything is in place.

  1. Open the Show View menu

    From the menu bar, choose Window → Show View → Other…

  2. Select the SDK Control Panel

    In the Show View dialog, expand the ENACT SDK category, select SDK Control Panel, and click Open.

  3. Confirm the SDK is running

    The Control Panel opens docked to the right, with a navigation bar of module tabs (Home, Application Packaging, Dataspaces and more). If not all tabs fit, use the ‹ › arrows at the ends of the bar to page through the rest (AI Assistant, Application Controller, Application Policies). You're ready to go.

Updating later

To get new releases, run Help → Check for Updates. The SDK upgrades in place, no manual uninstall needed.

AI Assistant does nothing / can't find a model?

Make sure a local Ollama server is running and a tool-capable model is pulled (7B+, e.g. qwen2.5). Smaller models may not emit tool calls reliably.
